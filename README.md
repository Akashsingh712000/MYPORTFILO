# My Portfolio

A personal portfolio website showcasing my **Full Stack development** skills, my experience at **Amazon**, and my top projects. Built to give recruiters and collaborators a clear picture of who I am and what I can do.

---

## ✨ Features

- **Neo-Brutalist Design** – Bold borders, high-contrast colors, and raw typography that make the site stand out from generic portfolio templates.
- **Custom Animations** – Smooth, hand-crafted animations including a scrolling **skills marquee** that highlights my technical toolkit without any third-party animation libraries.
- **Key Sections**
  - **About** – A quick intro covering my background, my time at Amazon, and what drives me as a developer.
  - **Skills** – An animated marquee that displays my full technical skill set at a glance.
  - **Journey** – A timeline of my professional and educational milestones.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **React** | Component-based UI and state management |
| **Vite** | Lightning-fast build tooling and dev server |
| **Vanilla CSS** | All styling written from scratch — no CSS frameworks or templates |

> Building complex UI with Vanilla CSS demonstrates a deep understanding of the cascade, flexbox, grid, and CSS custom properties without leaning on pre-built abstractions.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
