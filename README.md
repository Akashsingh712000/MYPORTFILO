# Personal Portfolio - Neo-Brutalist Web Design

Welcome to the repository for my personal portfolio! This site is a showcase of my skills as a Full Stack Developer, my professional experience (including my time at Amazon), and my top engineering projects.

The website features a striking **Neo-Brutalist** aesthetic, focusing on bold typography, high-contrast borders, and interactive animations to create a highly engaging user experience.

## ✨ Features
- **Modern Neo-Brutalist UI:** Custom CSS implementation featuring sharp borders, offset shadows, and vibrant highlight colors.
- **Dynamic Animations:** Custom CSS scroll reveals and infinite marquees for a lively feel.
- **Comprehensive Sections:** 
  - **About:** Details my journey from an AWS intern to building scalable MERN stack apps and currently exploring advanced cloud architecture.
  - **Skills:** A smooth infinite-scrolling marquee of my tech stack (React, Node, AWS, Docker, MongoDB, etc.).
  - **Journey/Experience:** A timeline of my professional experience, including Amazon operations, Urban Crust POS, and Vitto backend services.
- **Fully Responsive:** Adapts seamlessly to both desktop and mobile views.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js powered by Vite for lightning-fast HMR.
- **Styling:** Vanilla CSS (No external UI libraries, built entirely from scratch to achieve the exact Brutalist look).
- **Icons:** FontAwesome.

## 🚀 How to Run Locally

If you'd like to run this portfolio on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd your-repo-name/island
   ```
3. **Install the dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. **Open your browser:**
   Navigate to `http://localhost:5173/` to view the site.
